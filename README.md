# 🥩 Divina Carne

> Alimentando o mundo hoje. Preservando o amanhã.


## 🌐 Sobre o Projeto

O **Divina Carne** é um projeto fictício desenvolvido no âmbito do curso de Técnico Especialista em Qualidade e Sustentabilidade.  
O objetivo é representar, de forma prática, a aplicação de conceitos de:

- Qualidade  
- Segurança Alimentar  
- Sustentabilidade  
- Rastreabilidade  

Através de uma experiência digital moderna e intuitiva.


## 🚀 Tecnologias Utilizadas

- ⚛️ React  
- ⚡ Vite  
- 🎨 Tailwind CSS  
- 🎬 Framer Motion  
- 🌐 GitHub Pages (Deploy)


## 🧩 Estrutura do Projeto

O projeto foi desenvolvido com uma arquitetura baseada em componentes reutilizáveis:

- `Navbar` → Navegação principal  
- `Hero` → Apresentação inicial  
- `Animals` → Produção (Bovinos, Suínos e Aves)  
- `About` → Sobre a empresa  
- `Sig` → Sistema Integrado de Gestão  
- `Footer` → Créditos e informações finais  


## 🔗 Funcionalidades

- Navegação fluida entre secções  
- Layout responsivo  
- Animações suaves  
- Organização modular  
- Integração com links externos (YouTube, documentos SIG)  


## ⚠️ Desafios Encontrados

Durante o desenvolvimento, alguns desafios técnicos foram enfrentados:

- Diferença entre ambiente de desenvolvimento e produção  
- Problemas no carregamento de CSS após deploy  
- Incompatibilidade com versão do Tailwind CSS  


## 🛠️ Soluções Aplicadas

- Ajuste do `base` no Vite para GitHub Pages  
- Configuração correta do Tailwind CSS (versão estável)  
- Estruturação adequada do build para produção  
- Debug com análise de logs e comportamento do deploy

## 📌 Nota

Este projeto é fictício e foi desenvolvido exclusivamente para fins académicos.
Por não envolver dados reais ou sensíveis, não foi implementada uma abordagem aprofundada de segurança.  
As vulnerabilidades identificadas pelo `npm audit` foram analisadas e consideradas de baixo impacto no contexto do projeto, uma vez que se trata de uma aplicação estática sem backend ou manipulação de dados de utilizador.

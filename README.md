# 🥩 Divina Carne

Website institucional animado desenvolvido com foco em experiência moderna, design premium e interatividade.

---

## 🚀 Sobre o projeto

A **Divina Carne** é uma empresa fictícia criada no âmbito do projeto final do curso de **Técnico Especialista Nível 5 em Qualidade e Sustentabilidade**.

Este website foi desenvolvido como suporte digital ao projeto, com o objetivo de aplicar, de forma prática, os conhecimentos adquiridos ao longo da formação.

---

## 🎯 Objetivo

Desenvolver uma experiência digital envolvente para apresentar a empresa, destacando:

- Qualidade dos produtos  
- Sustentabilidade  
- Sistemas Integrados de Gestão (SIG)  
- Identidade visual forte e moderna  

---

## 🛠️ Tecnologias

- React  
- Vite  
- TailwindCSS  
- Framer Motion  

---

## ✨ Funcionalidades

- Scroll com animações suaves  
- Navbar fixa e interativa  
- Secções dinâmicas com expansão de conteúdo  
- Design responsivo  
- Microinterações modernas (hover, transições, animações)
